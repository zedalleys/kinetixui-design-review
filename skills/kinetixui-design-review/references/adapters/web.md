# Adapter: Web (framework-agnostic DOM/CSS)

1. **Detect.** `*.html`, `*.css|scss|less`, `package.json` with a bundler (vite, webpack, next, etc.), `<link rel=stylesheet>`, CSS custom properties, `tailwind.config.*`, `postcss.config.*`, CSS-in-JS packages. Use this adapter *in addition to* a framework adapter when the output is DOM.
2. **Where to look.** Token files (JSON/YAML → CSS variables), `:root`/theme selectors (`.dark`, `[data-theme]`, `prefers-color-scheme`), global styles, component stylesheets, SVG/icon sources, `@media`/`@container` breakpoints, `prefers-reduced-motion`, `forced-colors`, `dir`/`lang` handling on `<html>`/`<body>`, portal containers, test directories and CI a11y jobs.
3. **Static inspection (V1).** Leads: hex/rgb/hsl literals and `px` values in component styles; `z-index` and duration literals; physical properties (`left/right`, `margin-left`, `padding-right`, `text-align:left`) where logical ones exist; `outline: none` without a replacement focus style; `!important`; writes to `document.documentElement`/`body` from component code; `localStorage` writes in demo code; `role`/`aria-*` on elements that already have native semantics; images/icons without text alternatives.
4. **Runtime / gated (V2–V3).** With a browser: computed styles (`getComputedStyle`), `getBoundingClientRect` for clearance and overflow, the accessibility tree for names/roles/states, emulated media features (`prefers-reduced-motion`, `forced-colors`, `prefers-color-scheme`), viewport sizes at the project's breakpoints, 200% zoom (reflow), keyboard walk-through, `dir="rtl"` rendering. Gated: project lint/type/test/contrast/a11y scripts that are safe to run.
5. **Idiomatic checks.** Native elements before ARIA; logical properties; custom properties for tokens; focus-visible styling that survives themes; reduced-motion via media query; forced-colors tolerance for boundaries and focus.
6. **False positives.** `px` for 1px hairlines and artwork; physical properties in genuinely physical contexts (media, charts); `outline:none` paired with a visible `:focus-visible` replacement; ARIA that fills a real gap in a custom widget.
7. **Verification ceiling.** Source-only → V1. Dependency-free project scripts → V2. Browser available → V3 for layout, computed color/contrast, AX-tree, media emulation. Real assistive-technology behavior is **never** reachable here — say so.
