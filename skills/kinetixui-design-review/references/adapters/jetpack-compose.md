# Adapter: Jetpack Compose

1. **Detect.** `build.gradle(.kts)` with `androidx.compose` dependencies or Compose Multiplatform, `@Composable` functions, `MaterialTheme`/custom theme objects, `*.kt` UI files, `@Preview`.
2. **Where to look.** Composables and their parameters (the API), slot lambdas (`content: @Composable () -> Unit`), `Modifier` parameters, theme objects (`MaterialTheme`, `CompositionLocal`s for custom tokens, `ColorScheme`/`Typography`/`Shapes`), `LocalLayoutDirection`, `semantics {}` blocks, previews, UI tests (`createComposeRule`), screenshot tests, sample apps.
3. **Static inspection (V1).** Leads: literal `Color(0x…)`, `.dp`/`.sp` literals in reusable composables vs theme tokens; missing `Modifier` parameter on public composables; state not hoisted; missing `contentDescription` on meaningful images/icons or `semantics { }` for custom controls; `Modifier.clickable` without a role/semantics or minimum touch target (`minimumInteractiveComponentSize`); `Text("▾")`-style glyph icons vs `Icon`/vector assets; left/right (`Alignment.Left`, `padding(left=…)`) vs `start`/`end`; hard-coded text sizes ignoring font scale; animation without checking the animator-duration setting.
4. **Runtime / gated (V2–V3).** Needs the Android SDK/Gradle: `./gradlew test`, instrumented/Compose UI tests with semantics assertions, screenshot tests, previews with RTL/font-scale/dark-mode parameters. Usually unavailable in a bare container.
5. **Idiomatic checks.** Slot-based APIs; state hoisting; `Modifier` as first optional parameter; theme via `MaterialTheme`/`CompositionLocal`; `start`/`end`; semantics merging (`Modifier.semantics(mergeDescendants = true)`) for composite rows; vector/`Icon` for glyphs.
6. **False positives.** `Color(0x…)` inside the token definitions; decorative glyph text deliberately hidden from semantics; fixed `dp` for artwork.
7. **Verification ceiling.** Without Gradle/SDK: V1 only — mark Compose findings **source-only**. With the toolchain: V2 (tests), V3 (emulator/preview/semantics tree). TalkBack behavior needs a device/emulator run.
